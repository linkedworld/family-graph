# 한국 역사 인물 가계도 (목업)

한국 역사 인물의 가계를 그리고, 기준 인물에서 본 **호칭과 촌수**를 모든 인물에 자동으로 붙여 주는 웹사이트의 목업입니다.

사이트: https://linkedworld.github.io/family-graph/

| 가계도 | 데이터 파일 | 바로 가기 |
|---|---|---|
| 퇴계 이황(退溪 李滉, 1501–1570) | `data/yi-hwang.js` | `#yi-hwang` |
| 율곡 이이(栗谷 李珥, 1536–1584) | `data/yi-i.js` | `#yi-i` |
| 충무공 이순신(李舜臣, 1545–1598) | `data/yi-sunsin.js` | `#yi-sunsin` |
| 무의공 이순신(武毅公 李純信, 1554–1611) | `data/yi-sunsin-muui.js` | `#yi-sunsin-muui` |
| 오리 이원익(梧里 李元翼, 1547–1634) | `data/yi-wonik.js` | `#yi-wonik` |
| 다산 정약용(茶山 丁若鏞, 1762–1836) | `data/jeong-yakyong.js` | `#jeong-yakyong` |

주소 끝에 `#yi-i`처럼 가계도 id를 붙이면 그 가계도가 바로 열립니다. 버블 가계도(`index.html`)를 id 없이 열면 무의공 이순신 가계도가 기본으로 열립니다.

| 페이지 | 파일 | 내용 |
|---|---|---|
| 버블 가계도 (첫 화면) | `index.html` | 3D 구슬로 보는 자손의 관계망 |
| 가계도 | `tree.html` | 카드로 보는 계보도, 호칭·촌수 |
| 인물과 사건 | `events.html` | 가계도 인물이 얽힌 사건과 사건 사이의 인과(3D) |
| 광명의 명사 | `gwangmyeong.html` | 광명의 옛 인물 가계와 오늘의 명사를 한 시간축에(3D) |

화면 아래 도구 막대 왼쪽의 메뉴 단추(브레드크럼)로 페이지를 오갑니다. 보던 가계도와 기준 인물은 그대로 이어집니다.

## 실행

서버도 빌드도 필요 없는 순수 정적 웹입니다. **`index.html`을 브라우저로 바로 열면** 됩니다(`file://`). 카드 가계도는 `tree.html`입니다.
폴더째 GitHub Pages, Netlify 같은 정적 호스팅에 올려도 그대로 동작합니다.

- ES 모듈과 `fetch`를 쓰지 않고, 일반 `<script>`를 순서대로 읽습니다(`file://`에서도 막히지 않음).
- 데이터는 `data/*.js` 파일이 각각 가계도 하나를 `window.GENEALOGY_DATASETS` 목록에 넣어 줍니다.
- 배치 라이브러리 dagre는 `vendor/`에 포함되어 있어 인터넷 없이도 열립니다.
  인터넷이 없으면 웹 글꼴만 시스템 글꼴로 바뀝니다.

배포 규칙: `index.html`·`tree.html`은 CSS·JS·데이터를 `?v=버전`을 붙여 불러옵니다. 파일을 바꿔 배포할 때는 이 값을 모두 같은 새 값으로
올려 주세요(브라우저 캐시 때문에 예전 HTML과 새 스크립트가 섞이는 것을 막음). 값이 서로 다르면 `npm test`가 실패합니다.

엔진 테스트(개발용, Node 18 이상 · 선택 사항):

```bash
npm test
```

## 기능

- **가계도 고르기**: 위쪽 "가계도" 선택 상자에서 인물을 바꿉니다.
- **정통 표시**: 대를 잇는 맏아들의 흐름(종통)을 청록 겹선으로 그리고 줄기의 인물에 宗을 붙입니다. 시조 쪽 맨 윗대 조상과
  이름난 인물(데이터의 `meta.notable`)에서 시작하며, 그 집 양자가 있으면 양자, 적자가 없으면 서자 맏아들이 잇습니다.
  이름난 인물에는 名, 맏아들·맏딸은 출생 순서 글자를 굵게 강조합니다. 종통 줄기와 이름난 인물은 접혀 있어도 보입니다.
- **접기·펴기**: 처음에는 기준 인물의 직계(조상·자손)와 그 배우자만 보입니다. 숨은 자녀가 있는 카드의 `+N` 단추로 자녀를 펼치고,
  `−`로 다시 접습니다. 설정의 '모두 펼치기'·'직계만 보기'로 한꺼번에 바꿀 수 있고, 인물 찾기나 관계표에서 접힌 사람을 고르면
  그 사람까지 자동으로 펼쳐집니다.
- **가계도 다이어그램**: 세대별로 배치하며, 혼인은 점(•)으로 잇고 자녀는 그 점에서 내려옵니다. 첩과의 관계는 점선입니다.
  기준 인물의 부계 직계(조상·자손)는 카드를 세로 한 줄로 맞추고 직계 부모 카드에서 곧은 선으로 잇습니다.
- **기준 인물 바꾸기**: 위쪽 선택 상자에서 고르거나 카드를 두 번 누르면, 모든 카드의 호칭과 촌수가 그 사람 기준으로 다시 계산됩니다.
- **호칭 엔진**: 직계, 친가·외가·진외가 방계, 고모·이모·누이 계열, 혈족의 배우자, 배우자의 혈족, 사돈까지 다룹니다.
  규칙은 [docs/kinship-terms.md](docs/kinship-terms.md)에 정리했습니다.
- **미상 인물**: 기록이 없어도 관계상 반드시 존재하는 인물(자녀가 있는 혼인의 어머니, 중간 세대)을 "미상"으로 자동 생성하고
  호칭을 붙입니다(예: 외조모, 12대손).
- **미상 인물 숨기기**: 미상 인물을 빼고 그립니다. 중간 세대가 빠지면 점선과 "10대 미상" 표시로 직계를 잇습니다.
- **외가·처가 표시**: 끄면 시조 계열과 그 배우자만 남깁니다.
- **양자(출계)**: 양가(들어간 집)에서 내려오는 쪽빛 실선 '양자'와 생가(나온 집)에서 내려오는 점선 '출계'를 함께 그립니다.
  호칭은 족보 계통인 양가 기준이고, 생가 기준 관계가 다르면 "생가 기준 숙부 3촌"처럼 덧붙입니다.
  양자 본인에게 생가 부모는 생부·생모, 양가 부모는 양부·양모입니다.

## 버블 가계도 (`index.html`, 첫 화면)

시조의 자손을 3D 구슬로 그립니다. 세대는 위에서 아래로 층을 이루고(층마다 世 고리), 기준 인물의 직계 조상은 가운데 세로축에 섭니다.

- **색**: 기준 인물(빨강), 직계(금), 방계(가까운 촌수는 청록 → 먼 촌수는 보라), 배우자(분홍, 작은 구슬), 미상(회색). 이름난 인물은 빛나는 고리를 두릅니다.
- **남녀 표지**: 구슬 표면(화면에서 본 오른쪽 위)에 작은 원을 입힙니다. 남자는 청색 바탕에 男, 여자는 홍색 바탕에 女이고,
  직계·방계·배우자 모두 같습니다. 성별을 모르는 인물에는 없습니다. 멀리서는 색 점으로, 가까이서는 글자로 보입니다(인물과 사건 화면도 같음).
- **펼치기·접기**: 구슬을 누르면 자녀 구슬이 흘러나오고, 다시 누르면 구슬 안으로 들어갑니다. 접힌 자손이 있는 구슬은 반투명 껍질(버블)을
  두르고 자손 수만큼 커지며 `+N`이 붙습니다. 처음에는 시조에서 기준 인물까지의 직계만 펼쳐져 있습니다.
- **방계 보기·접기**(아래 도구 막대, 확대·축소 단추 왼쪽): 기본은 접기입니다. 기준 인물의 직계(조상·자손)와 가운데 축만 펼치고,
  방계 가지는 갈라지는 자리에서 부모 구슬 아래의 작은 구슬(선을 길게 눌러 자식을 부모 품에 넣은 것과 같은 모양)로 접습니다.
  종통 표시를 켜 두면 종통 줄기는 방계라도 펼쳐 보이고, 줄기에서 갈라지는 다른 방계만 접습니다.
  작은 구슬을 누르면 그 가지만 다시 나오고, '방계 보기'를 켜면 모든 방계를 펼쳐 보입니다. '모두 펼치기'도 방계 보기를 켭니다.
  선택은 이 브라우저에 기억됩니다.
- **사건**(설정의 칩, 기본 켬): 화면에 보이는 인물이 얽힌 사건(`data/events.js`)을 결정 모양으로 보입니다. 가계도는 그대로 두고,
  사건은 화면 왼쪽, 세대 고리 바깥 멀리에 그 인물과 같은 세대 높이로 세로로 늘어서며, 인물 구슬 가운데에서 나온 선이 사건에 닿습니다.
  같은 세대의 사건은 그 세대 띠 안에서 이른 것부터 위→아래로 쌓이고, 띠가 차면 바깥에 한 줄을 더 세웁니다. 화면을 돌려도 늘 왼쪽에 섭니다.
  사건을 누르면 상세(이 가계도의 인물 — 누르면 그 사람으로 이동, 다른 가계도·가계도 밖 인물, 이어진 사건, 출처)와 '인물과 사건에서 보기'가 나옵니다.
  선택은 이 브라우저에 기억됩니다.
- **종통 표시**(설정의 칩, 기본 켬): 시조와 이름난 남자 인물마다 대를 잇는 맏아들(양자 우선, 적자, 서자 순)의 흐름을
  청록 겹선으로 그리고 빛 마디를 흘려 보내며, 줄기의 인물 이름표에 宗을 붙입니다. 줄기는 끝까지 보이도록 펼쳐집니다.
  카드 가계도의 '정통 표시'와 같은 규칙입니다.
- **직계 자손 축**(설정의 칩): 켜면 기준 인물 아래로 대를 잇는 줄(종통 계승자, 없으면 맏이)도 가운데 축에 세우고, 그 줄이 끝까지
  보이도록 펼치며, 축을 따라 금빛 기둥을 그립니다. 직계 자손은 여러 갈래라 한 줄만 축에 서고 나머지는 그 둘레로 퍼집니다.
  선택은 이 브라우저에 기억됩니다.
- **탭으로 펼치기**(설정의 칩, 기본 켬): 켜면 구슬을 누르기만 해도 자녀를 펼치거나 접습니다. 끄면 누르기는 상세 카드만 열고,
  **길게 누르기**(약 0.5초)로 펼치거나 접습니다. 길게 누르는 동안 손가락 둘레에 원이 차오르고 구슬이 부풀다가, 시간이 차면
  진동과 함께 톡 터지듯 펼쳐집니다. 누르기에도 짧은 진동이 있습니다(진동을 지원하지 않는 iOS Safari 등에서는 진동 없이 동작).
- **상세 카드**: 오른쪽 위의 동그라미 ✕ 단추로 닫습니다. 휴대폰에서는 카드의 아무 곳이나 누르거나 빈 공간을 눌러도 닫히고,
  카드의 단추(자녀 펼치기·기준 인물로·가까이 보기)를 누르면 동작한 뒤 카드가 닫혀 바뀐 장면이 바로 보입니다.
- **조작**: 끌기 회전, 휠·두 손가락 확대, 오른쪽 끌기(또는 Shift+끌기)·두 손가락 이동, 방향키 회전. 잠시 손을 떼면 천천히 돌아갑니다(자동 회전).
  구슬에 마우스를 올리면 호칭·촌수, 누르면 오른쪽(휴대폰은 아래) 상세 패널이 열리고 '기준 인물로' 바꿀 수 있습니다.
- **렌더링**: three.js r158(`vendor/three.min.js`, 모듈이 아닌 일반 스크립트판이라 `file://`에서도 열림) 위에 직접 쓴 셰이더 —
  유리 구슬(프레넬 반사·얇은 막 무지갯빛·속심의 흐르는 빛), 조상에서 자손으로 빛이 흐르는 곡선 연결선, 성운·별 하늘, 홀로그램 바닥 —
  와 HDR 블룸·ACES 톤 매핑 후처리. WebGL2가 없으면 카드 가계도로 안내합니다.

## 인물과 사건 (`events.html`)

여섯 가계도의 인물이 얽힌 역사적 사건 85개와, 사건 사이의 관계 86개를 버블 가계도와 같은 3D 화면에 그립니다.

- **시간축**: 위에서 아래로 흐르며 50년마다 고리를 둡니다. 사건이 몰린 시기(예: 임진왜란 7년)는 넓게 펴서 겹치지 않게 합니다.
- **사건**: 종류(전쟁·전투·사화·옥사·정변·정책·학문·교육·종교·외교·기타)별 색의 결정 모양입니다. 기간이 있는 사건은 시작에서 끝까지 빛기둥을 세웁니다.
- **인물**: 가계도별 색의 유리 구슬입니다. 가계도마다 둘레의 한 방향을 맡으므로, 여러 집안이 한 사건에 모이는 모습이 드러납니다.
  두 가계도에 있는 사람(예: 태종)은 구슬 하나로 합칩니다. 가계도 밖의 주요 인물(임금, 상대편 등)은 회색 구슬입니다.
- **선**: 인물–사건(역할), 사건–사건(원인·결과로 이어짐·일부·영향·대립·계승). 사건 사이 선은 바깥으로 휜 아치이고, 빛이 원인에서 결과 쪽으로 흐릅니다.
- **가계 줄기**: 화면에 보이는 인물들을 가계도의 핏줄(조상 → 자손)로 잇습니다. 보이는 인물마다 위로 올라가 처음 만나는 '보이는 조상'과 잇고
  ("이원익은 이방원의 5대손"), 그래도 떨어진 덩어리는 같은 가계도의 가장 가까운 친척(숙부·장인 등)과 잇습니다.
  그래서 시대가 떨어진 사건들(예: 계유정난과 임진왜란)도 한 집안으로 이어져 보입니다. 설정의 '가계 줄기' 칩으로 켜고 끕니다.
- **선 누르기**: 선을 누르면 그 관계(사건 사이 인과, 인물의 역할, 가계 줄기)가 상세 패널에 나옵니다.
- **고르기**: 사건이나 인물을 누르면 이어진 관계만 밝게 남고, 상세 패널에 참여 인물(가계도별)·역할·이어진 사건·출처가 나옵니다.
  인물 패널에서 그 사람의 가계도(버블 가계도)로 바로 갈 수 있습니다.
- **거르기**: 가계도 칩, 사건 종류, 사건 인과·가계도 밖 인물 표시, 사건·인물 찾기. 다른 페이지에서 메뉴로 오면 보던 가계도부터 보입니다.
- **데이터**: `data/events.js`(사건마다 출처 포함). 집안별로 조사한 뒤 같은 사건(임진왜란·병자호란)은 하나로 합쳤고,
  자료끼리 어긋나는 점(예: 십만양병설 진위 논란, 이승훈 세례 연도)은 사건 설명에 적었습니다. `npm test`가 인물 id·관계·출처를 검사합니다.

## 광명의 명사 (`gwangmyeong.html`)

광명시의 과거와 현재를 한 화면의 가로 시간축(왼쪽 과거 → 오른쪽 현재, 가로로 펼친 연표)에 올린 페이지입니다.
카메라만 옆으로 눕혀 보므로 위아래로 끌면 시간축 둘레로 돌고, 연도는 고리 아래에 붙습니다. 엔진은 인물과 사건(`js/events.js`)을 그대로 쓰고,
`<body data-scope="gwangmyeong">`일 때 `data/gwangmyeong.js`만 읽습니다.

- **옛 인물(가계도)**: 오리 이원익(소하동 종택·관감당·충현서원·충현박물관)과 **민회빈 강씨 가계**(`data/geumcheon-kang.js`, 노온사동 영회원과
  금천강씨 묘역). 강석기 위로 직계, 민회빈의 자녀·손자·증손까지 싣고, 소현세자 가례·심양 볼모·강빈 옥사·복위·영회원 개칭을 사건으로 잇습니다.
- **광명의 옛 명사**: 가계도 밖의 공인(정원용, 시흥 농민봉기·소하리 3·1 만세운동의 인물, 시인 기형도).
- **오늘의 명사 30명**: 광명시장, 광명 지역 국회의원·경기도의원·광명시의원, 위키백과 '광명시 출신' 분류의 문화·체육인.
  **공적 정보만** 싣습니다 — 직함·정당·선거구·공적 이력·대표 활동과 출처. 가족·주소·연락처·SNS 관계는 조사하지도 싣지도 않으며,
  `npm test`가 명단에 다른 칸이 생기면 실패합니다. 의혹·고발 같은 사안도 넣지 않았습니다.
- **사건**: 선거·의회 원 구성·데뷔·메달 같은 공적 사건과 행정 연혁(금천현 → 시흥현 → 시흥군 → 광명시). 인물이 없는 지역 사건은 배경으로 늘 보입니다.
- **같은 무리 선**: 가계도가 없는 명단 인물은 같은 무리끼리 시간 순으로 가는 선으로 이어 화면이 한 덩어리가 되게 했습니다. 혈연이나 인맥이 아닙니다.
- **확인 안 된 점**: 온유·박현빈은 출생지가 자료마다 달라 광명 출생을 확인하지 못했습니다(카드에 밝힘). 박성민 의원의 소속(무소속/더불어민주당)과
  상임위원회 이름은 보도와 의회 누리집이 달라 둘 다 적었습니다. 2026년 이후 바뀐 직책은 반영되지 않았을 수 있습니다.

## 데이터 형식

가계도를 추가하려면 같은 형식의 `data/<인물>.js`를 만들고 `index.html`과 `tree.html`에 `<script src="data/<인물>.js">` 한 줄씩 더하면
선택 목록에 나옵니다. `npm test`의 형식 검사가 잘못된 참조나 빠진 출처를 찾아 줍니다.

```js
(window.GENEALOGY_DATASETS = window.GENEALOGY_DATASETS || []).push({
  "meta": { "id": "yi-hwang", "title": "퇴계 이황(退溪 李滉) 가계도", "subject": "yi_hwang",
            "sources": { "wiki_yihwang": { "title": "...", "url": "..." } } },
  "persons": [
    {
      "id": "yi_hwang", "name": "이황", "hanja": "李滉", "gender": "M",
      "clan": "진성 이씨", "gen": 7,          // 본관, 세(世)
      "sibIndex": 7,                          // 같은 아버지 자녀 중 출생 순서(손위·손아래 판정)
      "birth": "1501", "death": "1570", "pen": "퇴계(退溪)", "courtesy": "경호(景浩)",
      "note": "...", "sources": ["wiki_yihwang"]
    },
    { "id": "yeongyang_kim", "name": null, "gender": "F", "clan": "영양 김씨" }  // 이름 미상
  ],
  "unions": [
    // type: 정실 | 계실 | 첩, order: 혼인 순서. 한쪽 배우자가 null이고 자녀가 있으면 미상 인물이 생성된다.
    { "id": "u_sik_2", "husband": "yi_sik", "wife": "chuncheon_park", "type": "계실", "order": 2,
      "children": ["yi_seorin", "yi_ui", "yi_hae", "yi_jing", "yi_hwang"] }
  ],
  "adoptions": [
    // 양자: child는 생가 혼인의 children에 그대로 두고, 들어간 집의 혼인(union)을 적는다.
    { "id": "ad_jaeun", "child": "jeong_jaeun", "union": "u_jiyeol", "note": "작은할아버지 정지열의 양자로 출계" }
  ],
  "lineageGaps": [
    // 이안도의 11대손이 이충호라는 기록만 있을 때, 사이의 10세대를 미상으로 채운다.
    { "id": "gap_jongson", "ancestor": "yi_ando", "descendant": "yi_chungho", "generations": 11, "confidence": "추정" }
  ]
});
```

인물별 출처는 데이터의 `sources` 필드와 화면의 상세 패널에 나옵니다. 자료끼리 어긋나는 부분은 어느 쪽을 따랐는지 각 인물의 `note`에 적었습니다.

**알려진 빈칸**: 문헌에서 확인되지 않는 이름은 '미상'으로 두었습니다(예: 이황의 주촌파 중간 2대, 덕수 이씨 함종공파의 육촌 이하,
정씨 정도복 계열의 후손). 이 빈칸을 채우려면 각 문중의 족보 원본이 필요합니다. 목업 데이터이므로 실제 서비스 전에 족보로 검증해야 합니다.
