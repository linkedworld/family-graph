# 한국 역사 인물 가계도 (목업)

한국 역사 인물의 가계를 그리고, 기준 인물에서 본 **호칭과 촌수**를 모든 인물에 자동으로 붙여 주는 웹사이트의 목업입니다.

사이트: https://lonycell.github.io/videojs-simpleoverlay/

| 가계도 | 데이터 파일 | 바로 가기 |
|---|---|---|
| 퇴계 이황(退溪 李滉, 1501–1570) | `data/yi-hwang.js` | `#yi-hwang` |
| 율곡 이이(栗谷 李珥, 1536–1584) | `data/yi-i.js` | `#yi-i` |
| 충무공 이순신(李舜臣, 1545–1598) | `data/yi-sunsin.js` | `#yi-sunsin` |
| 다산 정약용(茶山 丁若鏞, 1762–1836) | `data/jeong-yakyong.js` | `#jeong-yakyong` |

주소 끝에 `#yi-i`처럼 가계도 id를 붙이면 그 가계도가 바로 열립니다.

## 실행

서버도 빌드도 필요 없는 순수 정적 웹입니다. **`index.html`을 브라우저로 바로 열면** 됩니다(`file://`).
폴더째 GitHub Pages, Netlify 같은 정적 호스팅에 올려도 그대로 동작합니다.

- ES 모듈과 `fetch`를 쓰지 않고, 일반 `<script>`를 순서대로 읽습니다(`file://`에서도 막히지 않음).
- 데이터는 `data/*.js` 파일이 각각 가계도 하나를 `window.GENEALOGY_DATASETS` 목록에 넣어 줍니다.
- 배치 라이브러리 dagre는 `vendor/`에 포함되어 있어 인터넷 없이도 열립니다.
  인터넷이 없으면 웹 글꼴만 시스템 글꼴로 바뀝니다.

배포 규칙: `index.html`은 CSS·JS·데이터를 `?v=버전`을 붙여 불러옵니다. 파일을 바꿔 배포할 때는 이 값을 모두 같은 새 값으로
올려 주세요(브라우저 캐시 때문에 예전 HTML과 새 스크립트가 섞이는 것을 막음). 값이 서로 다르면 `npm test`가 실패합니다.

엔진 테스트(개발용, Node 18 이상 · 선택 사항):

```bash
npm test
```

## 기능

- **가계도 고르기**: 위쪽 "가계도" 선택 상자에서 인물을 바꿉니다.
- **정통 표시**: 대를 잇는 맏아들의 흐름(종통)을 청록 겹선으로 그리고 줄기의 인물에 宗을 붙입니다. 시조 쪽 맨 윗대 조상과
  이름난 인물(데이터의 `meta.notable`)에서 시작하며, 그 집 양자가 있으면 양자, 적자가 없으면 서자 맏아들이 잇습니다.
  이름난 인물에는 名, 맏아들·맏딸은 출생 순서 글자를 굵게 강조합니다. 종통 줄기와 이름난 인물은 접혀 있어도 보입니다.
- **접기·펴기**: 처음에는 기준 인물의 직계(조상·자손)와 그 배우자만 보입니다. 숨은 자녀가 있는 카드의 `+N` 단추로 자녀를 펼치고,
  `−`로 다시 접습니다. 설정의 '모두 펼치기'·'직계만 보기'로 한꺼번에 바꿀 수 있고, 인물 찾기나 관계표에서 접힌 사람을 고르면
  그 사람까지 자동으로 펼쳐집니다.
- **가계도 다이어그램**: 세대별로 배치하며, 혼인은 점(•)으로 잇고 자녀는 그 점에서 내려옵니다. 첩과의 관계는 점선입니다.
  기준 인물의 부계 직계(조상·자손)는 카드를 세로 한 줄로 맞추고 직계 부모 카드에서 곧은 선으로 잇습니다.
- **기준 인물 바꾸기**: 위쪽 선택 상자에서 고르거나 카드를 두 번 누르면, 모든 카드의 호칭과 촌수가 그 사람 기준으로 다시 계산됩니다.
- **호칭 엔진**: 직계, 친가·외가·진외가 방계, 고모·이모·누이 계열, 혈족의 배우자, 배우자의 혈족, 사돈까지 다룹니다.
  규칙은 [docs/kinship-terms.md](docs/kinship-terms.md)에 정리했습니다.
- **미상 인물**: 기록이 없어도 관계상 반드시 존재하는 인물(자녀가 있는 혼인의 어머니, 중간 세대)을 "미상"으로 자동 생성하고
  호칭을 붙입니다(예: 외조모, 12대손).
- **미상 인물 숨기기**: 미상 인물을 빼고 그립니다. 중간 세대가 빠지면 점선과 "10대 미상" 표시로 직계를 잇습니다.
- **외가·처가 표시**: 끄면 시조 계열과 그 배우자만 남깁니다.
- **양자(출계)**: 양가(들어간 집)에서 내려오는 쪽빛 실선 '양자'와 생가(나온 집)에서 내려오는 점선 '출계'를 함께 그립니다.
  호칭은 족보 계통인 양가 기준이고, 생가 기준 관계가 다르면 "생가 기준 숙부 3촌"처럼 덧붙입니다.
  양자 본인에게 생가 부모는 생부·생모, 양가 부모는 양부·양모입니다.

## 파일 구성

| 경로 | 내용 |
|---|---|
| `index.html`, `css/style.css` | 화면 |
| `js/app.js` | 화면 동작(다이어그램, 상세 패널, 관계표, 확대·이동) |
| `js/model.js` | 가계 데이터를 그래프 모델로 변환, 미상 인물 생성 |
| `js/kinship.js` | 호칭·촌수 계산 엔진 |
| `js/layout.js` | 표시할 노드·간선 구성(숨김 처리 포함)과 dagre 배치 |
| `data/*.js` | 가계도 데이터 목업 (이황, 이이, 이순신, 정약용) |
| `vendor/dagre.min.js` | 그래프 배치 라이브러리 dagre 0.8.5 (MIT, `vendor/dagre.LICENSE`) |
| `docs/kinship-terms.md` | 호칭·촌수 규칙 정리 |
| `tests/kinship.test.mjs` | 엔진 테스트 (이황 데이터 + 가상 가족) |

## 데이터 형식

가계도를 추가하려면 같은 형식의 `data/<인물>.js`를 만들고 `index.html`에 `<script src="data/<인물>.js">` 한 줄을 더하면
선택 목록에 나옵니다. `npm test`의 형식 검사가 잘못된 참조나 빠진 출처를 찾아 줍니다.

```js
(window.GENEALOGY_DATASETS = window.GENEALOGY_DATASETS || []).push({
  "meta": { "id": "yi-hwang", "title": "퇴계 이황(退溪 李滉) 가계도", "subject": "yi_hwang",
            "sources": { "wiki_yihwang": { "title": "...", "url": "..." } } },
  "persons": [
    {
      "id": "yi_hwang", "name": "이황", "hanja": "李滉", "gender": "M",
      "clan": "진성 이씨", "gen": 7,          // 본관, 세(世)
      "sibIndex": 7,                          // 같은 아버지 자녀 중 출생 순서(손위·손아래 판정)
      "birth": "1501", "death": "1570", "pen": "퇴계(退溪)", "courtesy": "경호(景浩)",
      "note": "...", "sources": ["wiki_yihwang"]
    },
    { "id": "yeongyang_kim", "name": null, "gender": "F", "clan": "영양 김씨" }  // 이름 미상
  ],
  "unions": [
    // type: 정실 | 계실 | 첩, order: 혼인 순서. 한쪽 배우자가 null이고 자녀가 있으면 미상 인물이 생성된다.
    { "id": "u_sik_2", "husband": "yi_sik", "wife": "chuncheon_park", "type": "계실", "order": 2,
      "children": ["yi_seorin", "yi_ui", "yi_hae", "yi_jing", "yi_hwang"] }
  ],
  "adoptions": [
    // 양자: child는 생가 혼인의 children에 그대로 두고, 들어간 집의 혼인(union)을 적는다.
    { "id": "ad_jaeun", "child": "jeong_jaeun", "union": "u_jiyeol", "note": "작은할아버지 정지열의 양자로 출계" }
  ],
  "lineageGaps": [
    // 이안도의 11대손이 이충호라는 기록만 있을 때, 사이의 10세대를 미상으로 채운다.
    { "id": "gap_jongson", "ancestor": "yi_ando", "descendant": "yi_chungho", "generations": 11, "confidence": "추정" }
  ]
});
```

## 가계도별 범위와 출처

네 가계도 모두 주인공 기준 **방계 10촌까지** 문헌에서 확인되는 인물을 실었습니다(직계 조상·후손은 10촌을 넘어도 수록).
`node tools/check-dataset.cjs <id> --list`로 인물별 호칭·촌수를 볼 수 있습니다.

| 가계도 | 인물 | 혈족 | 주요 범위 |
|---|---|---|---|
| 퇴계 이황 | 300 | 157 | 형제 7남 1녀의 자녀·손자, 숙부 이우 계열, 주촌파·마애파 육촌~십촌, 9대손 이야순, 외가·처가 |
| 율곡 이이 | 220 | 121 | 고조부 이추, 이의무·이기·이행 계열(이안눌 9촌, 이식 10촌), 외가 신자승·남휘, 이종사촌 권처균 |
| 충무공 이순신 | 139 | 80 | 시조 이돈수부터 직계, 5대손 이봉상까지 종손 계통, 종8대조부 이윤운(10촌), 외가·진외가·처가 |
| 다산 정약용 | 274 | 136 | 시조 정윤종부터 직계, 형제·사촌 계열, 외가 해남 윤씨(윤선도~윤두서, 외사촌 윤지충), 6세손 정해인 |

인물 수에는 기록이 없어 자동 생성된 '미상' 인물이 포함됩니다.

**출처**: 한국고전종합DB의 문집 원문(퇴계집·고봉집·번암집·여유당전서의 묘지명·묘갈명·행장 등), 한국민족문화대백과사전,
한국역대인물 종합정보시스템, 디지털○○문화대전(안동·아산·여수·청주·해남), 위키백과 인물 문서.
인물별 출처는 데이터의 `sources` 필드와 화면의 상세 패널에 나옵니다. 자료끼리 어긋나는 부분은 어느 쪽을 따랐는지 각 인물의 `note`에 적었습니다.

**알려진 빈칸**: 문헌에서 확인되지 않는 이름은 '미상'으로 두었습니다(예: 이황의 주촌파 중간 2대, 덕수 이씨 함종공파의 육촌 이하,
정씨 정도복 계열의 후손). 이 빈칸을 채우려면 각 문중의 족보 원본이 필요합니다. 목업 데이터이므로 실제 서비스 전에 족보로 검증해야 합니다.
