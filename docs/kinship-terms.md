# 한국 친족 호칭·촌수 정리

가계도 엔진(`js/kinship.js`)이 따르는 규칙입니다. 국립국어원 『표준 언어 예절』(2011)과
표준국어대사전의 정의를 기준으로 하되, 조선 시대 족보 문맥에 필요한 호칭(전모·계모·서모·적모 등)을 더했습니다.

## 1. 촌수 계산 원리

- 부모와 자식 사이가 **1촌**입니다. 두 사람의 촌수는 가장 가까운 공통 조상까지 올라간 세대 수(상향)와
  내려온 세대 수(하향)를 더한 값입니다.
- 형제자매는 부모에서 만나므로 1+1 = **2촌**입니다.
- 부부는 **무촌(0촌)** 입니다.
- 인척의 촌수는 배우자의 혈족이면 배우자와 그 혈족 사이의 촌수, 혈족의 배우자면 그 혈족과의 촌수를 따릅니다.

엔진은 상향 세대 수 `up`, 하향 세대 수 `down`으로 다음 두 값을 씁니다.

| 값 | 뜻 |
|---|---|
| `g = up − down` | 대상이 기준보다 몇 세대 위(+)/아래(−)인가 |
| `c = min(up, down) − 1` | 방계 차수. 0이면 형제 계열, 1이면 사촌 계열, 2면 육촌 계열… |

방계 접두어는 `c`에 따라 **(없음) → 종(從) → 재종(再從) → 삼종(三從) → 사종 …** 으로 늘어납니다.

## 2. 직계

| 세대 | 존속(남/여) | 비속(남/여) |
|---|---|---|
| 1 | 부(아버지) / 모(어머니) | 아들 / 딸 |
| 2 | 조부(할아버지) / 조모(할머니) | 손자 / 손녀 |
| 3 | 증조부 / 증조모 | 증손자 / 증손녀 |
| 4 | 고조부 / 고조모 | 현손자 / 현손녀 |
| 5 | 현조부(5대조) / 현조모 | 5대손(내손) |
| n | n대조부 / n대조모 | n대손 |

- 어머니 쪽 존속: **외조부·외조모, 외증조부 …**
- 아버지의 외가(진외가, 陳外家): **진외조부**(아버지의 외할아버지), **진외조모**
- 딸을 거친 비속: **외손자·외손녀, 외증손 …**

## 3. 친가(부계) 방계

| g \ c | 0 (형제 계열) | 1 (사촌 계열) | 2 (육촌 계열) | 3 (팔촌 계열) |
|---|---|---|---|---|
| +3 | 종증조부 (5촌) | 재종증조부 (7촌) | 삼종증조부 (9촌) | |
| +2 | 종조부 (4촌, 큰/작은할아버지) · 대고모(왕고모) | 재종조부 (6촌) · 종대고모 | 삼종조부 (8촌) | |
| +1 | 백부·숙부 (3촌, 큰/작은아버지) · 고모 | 종숙=당숙 (5촌) · 종고모=당고모 | 재종숙 (7촌) | 삼종숙 (9촌) |
| 0 | 형·아우·누나·누이동생 (2촌) | 종형제=사촌 (4촌) | 재종형제=육촌 (6촌) | 삼종형제=팔촌 (8촌) |
| −1 | 조카(질)·질녀 (3촌) | 종질=당질 (5촌) | 재종질 (7촌) | 삼종질 (9촌) |
| −2 | 종손·종손녀 (4촌) | 재종손 (6촌) | 삼종손 (8촌) | |
| −3 | 종증손 (5촌) | 재종증손 (7촌) | | |

- 형제 호칭은 기준 인물의 성별에 따라 다릅니다. 남자는 형·아우·누나·누이동생, 여자는 오빠·남동생·언니·여동생입니다.
- 사촌 이상에서는 종형/종제, 종자/종매처럼 한자 호칭을 대표로 쓰고, "사촌 형" 같은 일상 호칭을 함께 보여 줍니다.
- 아버지는 같고 어머니가 다르면 **이복**(異腹), 어머니는 같고 아버지가 다르면 **이부**(異父)를 붙입니다.
- 백부·숙부의 구분은 아버지와 비교한 손위·손아래로 정합니다. 출생 순서(`sibIndex`)를 먼저 보고, 없으면 출생 연도를 봅니다.

## 4. 외가·고모·이모 계열

| 관계 | 호칭 | 촌수 |
|---|---|---|
| 어머니의 남자 형제 | 외숙(외삼촌) | 3 |
| 어머니의 여자 형제 | 이모 | 3 |
| 외삼촌의 자녀 | 외종형제(외사촌) | 4 |
| 이모의 자녀 | 이종형제(이종사촌) | 4 |
| 고모의 자녀 | 내종형제(고종사촌) | 4 |
| 누이의 자녀 | 생질·생질녀 | 3 |
| 외조부의 형제 | 외종조부 | 4 |
| 어머니의 사촌 | 외종숙(외당숙) | 5 |
| 아버지의 외삼촌 | 진외종조부 | 4 |

표에 없는 섞인 계통은 경로 위의 한 사람을 기준으로 두 호칭을 잇습니다(예: "조부의 외조부").
그래도 정할 수 없으면 "아버지의 어머니의 오빠"처럼 경로를 풀어 씁니다.

## 5. 혈족의 배우자

| 혈족 | 그 배우자 |
|---|---|
| 아버지(어머니가 아닌 부인) | 정실이면 **전모**(앞선 부인)·**계모**(뒤 부인), 첩이면 **서모**. 첩의 소생에게 아버지의 정실은 **적모** |
| 조부(조모가 아닌 부인) | 전조모·계조모·서조모 |
| 어머니(아버지가 아닌 남편) | 계부(의부) |
| 백부 / 숙부 | 백모(큰어머니) / 숙모(작은어머니) |
| 종숙·재종숙 | 종숙모·재종숙모 |
| 종조부 | 종조모 |
| 고모 / 대고모 / 이모 | 고모부 / 대고모부 / 이모부 |
| 외숙 | 외숙모 |
| 형 / 아우 (남자 기준) | 형수 / 제수(계수) |
| 누나 / 누이동생 (남자 기준) | 자형(매형) / 매부(매제) |
| 오빠·남동생 (여자 기준) | 올케 |
| 언니 / 여동생 (여자 기준) | 형부 / 제부 |
| 아들 / 딸 | 며느리(자부) / 사위(서) |
| 손자 / 손녀 | 손부 / 손서 |
| 조카 / 질녀 | 질부 / 질서 |

## 6. 배우자의 혈족

| 배우자의 | 남편 입장(아내의 혈족) | 아내 입장(남편의 혈족) |
|---|---|---|
| 아버지 | 장인(빙부) | 시아버지(시부) |
| 어머니 | 장모(빙모) | 시어머니(시모) |
| 손위 남자 형제 | 처남 | 아주버니(시숙) |
| 손아래 남자 형제 | 처남 | 시동생(시숙) |
| 손위 여자 형제 | 처형 | 시누이(형님) |
| 손아래 여자 형제 | 처제 | 시누이(아가씨) |
| 그 밖의 혈족 | 처 + 호칭 (처조부, 처숙부, 처조카 …) | 시 + 호칭 (시조부, 시숙부 …) |
| 자녀(내 소생이 아님) | 의붓아들·의붓딸 | 의붓아들·의붓딸 |
| 부모의 다른 배우자 | 처전모·처계모 | 시전모·시계모 |

배우자 혈족의 배우자:

| 관계 | 남편 입장 | 아내 입장 |
|---|---|---|
| 배우자의 남자 형제의 배우자 | 처남댁 | 동서 |
| 배우자의 여자 형제의 배우자 | 동서 | 시누이 남편 |

남편의 다른 부인은 혼인 순서에 따라 **전처**(선실)·**후처**(후실), 첩이면 **남편의 첩**이라 부르고, 첩의 입장에서 정실은 **정실 부인**(큰댁)이라 부릅니다.

## 7. 사돈

자녀의 배우자의 부모는 **사돈**입니다. 남자는 바깥사돈, 여자는 안사돈입니다.

## 8. 미상 인물

- `name`이 없고 본관(`clan`)도 없으면 **미상**으로 표시합니다. 다이어그램의 "미상 인물 숨기기" 대상입니다.
- 이름은 전하지 않지만 본관이 전하는 인물(예: 영양 김씨)은 본관으로 표시하고 "이름 미상" 표지를 붙입니다.
- 자녀가 있는 혼인에서 부모 한쪽이 기록에 없으면, 그 사람은 반드시 존재하므로 엔진이 미상 인물을 만듭니다.
- `lineageGaps`로 "A의 n대손 B"를 적으면, 사이의 n−1세대를 미상 인물로 채웁니다.
- 미상 인물에게도 호칭과 촌수를 그대로 붙입니다(예: 외조모 2촌, 12대손 12촌).

## 9. 양자(출계)

족보는 양자를 들어간 집(양가)의 자손으로 적습니다. 엔진도 **양가 기준**으로 대표 호칭과 촌수를 정하고,
생가 기준 관계가 다르면 함께 보여 줍니다.

| 관계 | 호칭 |
|---|---|
| 양자 본인 → 들어간 집의 부모 | 양부·양모 |
| 양자 본인 → 낳아 준 부모 | 생부·생모(본생부·본생모) |
| 양부·양모 → 양자 | 양자(계자)·양녀 |
| 생부·생모 → 양자로 간 자녀 | 출계한 아들·딸 |
| 그 밖의 친족 | 양가 기준 호칭 + "생가 기준 ○○ n촌" |

예: 정약용에게 작은할아버지 정지열의 양자로 간 숙부 정재운은 양가 기준 **종숙(당숙) 5촌**이고, 생가 기준으로는 **숙부 3촌**입니다.
양가 쪽으로는 혈연이 없고 생가 쪽으로만 이어지는 사람은 "생가 형"처럼 앞에 **생가**를 붙입니다.
